## Intent and design

Adapt wide-search-toolkit v0.2.0 using Bun.secrets under service rollbar-toolkit. Keep synchronous resolveConfig, add asynchronous loadConfig with provenance and graceful keychain failures. Explicit environment and nearest .env outrank keychain, then existing saved configuration. CLI auth operations inject SecretStore and never accept secret values in argv. MCP reads on each call and exposes no secret mutations.

## Acceptance criteria

SDK precedence, disabled/unavailable stores, missing-only reads; CLI hidden prompting, explicit stdin, redacted list, migration and dry runs; MCP per-call reload; documentation and minor release. Tests use fake stores and spawned processes disable keychain.

## Non-goals

No plaintext fallback, new profiles, or file cleanup during migration.

## Spec delta

D1: Add OS keychain credential source and auth command surface with requested precedence.
D2: MCP automatically loads credentials per invocation.

## Decisions

Use Bun.secrets per user ruling; entry names match primary environment variables. Existing profiles remain supported as lower-priority configuration.

## Rulings

Resources project/account each map to their corresponding token; rollbar maps to both for bulk operations. Cost if wrong: low, CLI vocabulary only.

## Docs impact

README, SDK/CLI/MCP policies, configuration/security guides, .env.example, agent-context, changelog and release versions.
